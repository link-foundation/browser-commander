### Added

- Chrome for Testing gets the `chrome-for-testing` default restrictions, `no-chrome-for-testing-infobar` (`--test-type=gpu`) and `mock-keychain` (`--use-mock-keychain`), which hide its "only for automated testing" bar and keep it from the macOS keychain. `default_restrictions` replaces them (`[]` turns them off), results report them as `default_restrictions`, and `CHROME_FOR_TESTING_RESTRICTIONS`, `is_chrome_for_testing()` and `default_restrictions_for()` are exported (issue #179).

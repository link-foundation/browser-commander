### Changed

- Launches without `channel` or `executable_path` start Chrome for Testing (Playwright's download, or for Selenium the one Selenium Manager keeps) instead of the installed Google Chrome, which is now used only on request and never as a silent fallback. A Chrome for Testing launch gets the new `chrome-for-testing` restriction preset by default (`no-chrome-for-testing-infobar`, i.e. `--test-type=gpu`, and `mock-keychain`); pass `default_restrictions` to change it. New helpers: `is_chrome_for_testing`, `default_restrictions_for` and `CHROME_FOR_TESTING_RESTRICTIONS`.
